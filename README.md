# ZakoOpt (NeoForge 1.21.1)

Высокопроизводительный клиентский мод оптимизации рендеринга для **Minecraft 1.21.1 (NeoForge)** с расширенной поддержкой и оптимизациями под **Create**.

> **Оригинальный автор:** Zako ([Telegram-канал автора](https://t.me/StarikZako))  
> **Оригинальный репозиторий:** [3ako/ZakoOpt](https://github.com/3ako/ZakoOpt)

---

## ⚡ Особенности и оптимизации

### ⚙️ Интеграция и оптимизации Create (1.21.1)
- **Far Machines Rest (Покой дальних механизмов):** механизмы Create за пределами видимости (по умолчанию >80 блоков) пропускают клиентский тик анимации, сохраняя производительность при масштабных фабриках.
- **Factory Paths Cache (Кэш путей панелей):** стрелки и линии связи между панелями Factory Gauge компилируются один раз и переиспользуются, не перестраиваясь каждый кадр.
- **Item Meshes Cache (Кэш предметов на конвейерах и фильтрах):** кэширование мешей предметов, движущихся по конвейерным лентам (Create Belts) и фильтрам Value Box.
- **Package Address Pattern Cache:** однократная компиляция шаблонов адресов цепных конвейеров логистики.

### 🚀 Общие оптимизации рендера
- **Сущности (Entities):** LOD для дальних мобов и игроков, атлас скинов игроков, многопоточная сборка моделей.
- **Предметы (Items):** LOD для выброшенных предметов, пропуск избыточной покадровой сортировки полигонов.
- **Фермы и механизмы:** кэширование мобов в спавнерах, кэширование блоков при движении поршнями.
- **Частицы (Particles):** многопоточная сборка и оптимизация расчёта освещения.
- **Текст и интерфейс (HUD):** кэширование никнеймов, голограмм, чата, сайдбаров и табличек; плавное обновление HUD с частотой монитора.
- **Графический конвейер:** кольцевой буфер вершин (Ring Buffer), минимизация переключений фреймбуферов и ранний отсев невидимых блоков-сущностей.

## 📦 Сборка и установка

### Готовый JAR-артефакт
Собранный файл мода под NeoForge 1.21.1:
- `zakoopt-1.2.0+1.21.1-neoforge.jar` (551 КБ)

### Требования
- **Minecraft:** 1.21.1
- **Модлоадер:** NeoForge (>= 21.1.262)
- **Java:** Java 21 LTS
- **Совместимость:** Совместим с Create 6.0.10+, ImmediatelyFast, Sodium / Embeddium, Iris / Oculus, Lithium.
